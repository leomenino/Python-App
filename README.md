# Python-App

Coleção de pequenos projetos e scripts em Python, criados para praticar diferentes conceitos: manipulação de ficheiros, interfaces simples, lógica de negócio e processamento de imagem.

## 📂 Projetos

| Projeto | Descrição | Status |
|---|---|---|
| [Calculator](./Calculator) | Calculadora com interface estilizada em CSS | Concluído |
| [Expense_tracker](./Expense_tracker) | Script para registo e acompanhamento de despesas | Em desenvolvimento |
| [Image Editor](./Image%20Editor) | Editor de imagens com transformações usando funções lambda | Concluído |
| [Investment_Calculator](./Investment_Calculator) | Calculadora de retorno de investimentos | Quase concluído |
| [Random Words](./Random%20Words) | Script para organizar ficheiros por pastas | Concluído |
| [Saved](./Saved) | *(adicionar descrição)* | Quase concluído |

O ficheiro `expense.db` é a base de dados SQLite usada pelo projeto **Expense_tracker**.

## 🛠️ Tecnologias

- Python 3
- SQLite
- CSS (interface do Calculator)

## 🚀 Como correr

Cada pasta é independente. Entra na pasta do projeto que queres testar e corre o ficheiro principal:

```bash
cd Expense_tracker
python3 main.py
```

## 📌 Sobre

Repositório de aprendizagem — cada mini-app foca-se numa competência diferente (interfaces, ficheiros, bases de dados, processamento de imagem).
